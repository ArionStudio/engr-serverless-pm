# Superseded core architecture rules

Status: superseded

This document described an older core package contract and is no longer an
authority. In particular, it treated all services as private before the package
introduced the intentional `@lfspm/core/services` composition entry point.

  implementation rules.
- [Current core architecture](../core/architecture.md) for the implemented
  package structure and composition status.
